# Changelog

## 0.1.0

First release.

- WhatSync node: send a text, a Business API template or a group message; check a send's status; search messages; list chats, unanswered chats, a chat's messages, groups and templates; show the account; run any WhatSync tool.
- WhatSync Trigger: starts a workflow on new messages, sent messages, Business delivery updates and connection changes. Registers its webhook when the workflow is turned on, removes it when turned off, and checks every event's signature.
